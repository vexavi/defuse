# ESL Defuse

A simple two-role ESL communication game inspired by bomb-defusal party games.

## Roles

- **Defuser:** sees and controls the bomb.
- **Manual Reader:** sees the defusal manual, but should not see the bomb.

Students must communicate in English to clear every module before the timer reaches zero.

## Included modules

1. Color Panel
2. Wires
3. Animal Numbers
4. Directions
5. Category Words

The game is designed for low-level ESL learners and includes a "Useful English" section in the manual.

## Run locally

Open `index.html` in a browser.

## Put it on GitHub Pages

1. Create a new GitHub repository.
2. Upload:
   - `index.html`
   - `style.css`
   - `game.js`
3. Open the repository's **Settings**.
4. Go to **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.

GitHub will give you a public URL for the game.

## Classroom setup

The easiest setup is two devices:

- Device 1: open **Defuser → Start Bomb**
- Device 2: open **Manual Reader → Open Manual**

Put students back-to-back or use a folder/cardboard divider so the Manual Reader cannot see the bomb.

No server, database, login, or multiplayer backend is required.
