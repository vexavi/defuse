# ESL Defuse

A two-role ESL communication game for GitHub Pages.

## Roles

- **Defuser:** sees and controls the bomb.
- **Manual Reader:** uses the printed universal manual and gives instructions in English.

## Universal manual

The same `manual.html` works for every bomb.

You only need to print it once. The game randomizes which module variation appears, but the rules in the manual never change.

## Files

- `index.html` — game
- `style.css` — game styling
- `game.js` — game logic
- `manual.html` — universal printable manual
- `README.md`

## GitHub Pages

Upload all five files to the root of your GitHub repository:

```text
index.html
style.css
game.js
manual.html
README.md
```

Then enable GitHub Pages from the `main` branch and `/ (root)`.

The game opens from your normal GitHub Pages URL.

The printable manual is available at:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/manual.html
```
